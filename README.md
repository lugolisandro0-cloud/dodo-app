# DODO · Central

App de la banda DODO: radar de oportunidades (cruceros, eventos, temporadas), contactos con seguimiento, balance de plata, kit de prensa y mails de postulación. Android, Windows y Mac.

- **Cómo instalarla:** ver [LEEME.md](LEEME.md).
- **Descargas:** carpeta [`descargas`](descargas) (Android). Las apps de Windows y Mac se pasan por separado.
- Las apps instaladas leen `version.json` y se actualizan solas. El radar escribe `radar/radar.json`.
- No contiene datos privados de la banda: esos viven en la planilla de Google de cada uno.
